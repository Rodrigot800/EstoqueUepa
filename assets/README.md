# Recursos visuais

Esta pasta reúne os arquivos de identidade visual usados pelo Estoque UEPA.

| Arquivo | Uso no sistema |
| --- | --- |
| `logo principal.png` | Logo institucional exibida no cabeçalho. |
| `logo redondo.png` | Marca redonda exibida na barra lateral. |
| `logo quadrado.png` | Ícone do aplicativo web instalado. |
| `logo da aba.png` | Ícone da guia do navegador (favicon). |
| `UepaEstoqueIcone.png` e `.ico` | Ícones institucionais adicionais preservados para usos futuros. |
| `logo seg.png` e `Assinatura_Padrão_CampusXX_Castanhal_Avatar_Radial_Cores.png` | Variações institucionais preservadas para usos futuros. |

Os arquivos copiados para `frontend/public/` são os que o navegador utiliza diretamente. Ao trocar uma logo, atualize também a cópia correspondente e reconstrua a aplicação com `docker compose up -d --build`.
